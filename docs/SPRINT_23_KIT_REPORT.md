# Дополнение Sprint23: автономная проверка отчётов

Узкое продолжение после принятия основного результата в PR29. Риск низкий:
упаковка и инструкция; Rust, PostgreSQL и семантика преобразований не меняются.
Лимит этого этапа: 13:48:18–14:33:18 UTC, 23 октября 2026 года.

В Linux-поставку добавлены недостающий обязательный разборщик
`tools/oracle/audit-conversion-evidence.py` и русская инструкция. Раньше
проверяющий был включён без этой зависимости. Отдельный `checker-kit.zip`
позволяет проверить файлы без исходного checkout, сервера и установки библиотек.

Пять точных файлов: `tools/sprint23/audit-compact.py`,
`tools/sprint23/decode-report.py`, `tools/oracle/audit-conversion-evidence.py`,
`docs/SELF_CHECK_RU.md`, `SHA256SUMS`. Три инструмента совпадают с уже принятыми
байтами; в списке контрольных сумм четыре строки для четырёх остальных файлов.

ZIP: 22 456 байт; SHA-256
`020D9517DF44BF7EC5D97BD81945729FD71C2EA9E181900E1FBF6D4406BF1509`.
Его состав и каждый извлечённый файл независимо сверены до запуска.

Приёмка проверяет обычный и компактный отчёты сохранённого примера X01,
авторское ядро из двух разных событий Unicode и точные байты декодированного JSON.
Три отрицательных случая: подмена исходника, подмена результата и существующий
выходной файл без перезаписи. Генератор и преобразователь не запускаются.

Изолированная проверка окончательного ZIP прошла: 3 процесса, 6 полных потоков,
обе семантические проверки и все три ожидаемых отказа. На момент фиксации кандидата
публичные CI и скачивание именно этого ZIP ещё ожидаются. Итоговая квитанция
будет в описании отдельного PR. Это не скачивание или проверка всей Linux-поставки,
не доказательство запуска преобразователя и не закрытие всех R5.

# Sprint26: сохраняемые оценки BPMN

Кандидат 0.9.0 после PR38 (`4ac5d20f`). Полная приёмка, CI и выпуск нового
релизного бинарника пока не объявлены.

Из модели можно запустить сохраняемую оценку выбранного журнала. История
показывает этапы и исход; отчёт содержит точные входы, версии, методику и
ограничения. JSON можно скачать и проверить отдельно без базы данных.
Отмена сохраняется. При перезапуске незавершённая задача явно прерывается,
входы остаются, повтор запускается пользователем. Старые отчёты не пересчитываются
при обычном чтении. Неподдержанная модель и пустой журнал сохраняют честный
самостоятельный исход, без вымышленных чисел.

Формат БД расширен до v4. Заполненная v3 требует явной офлайн-команды
`--migrate-storage`; автоматического изменения при запуске нет. Проверено,
что прежний бинарник отказывает v4 до записи. При восстановлении копии
численные отчёты перепроверяются до создания проекта; пересчитанные внешние
хеши поддельной оценки не превращают её в подтверждённый результат.

Проверено локально: восемь коротких тестов, Clippy всех целей и сборка;
полный набор всех целей — 195 passed, 0 failed, 27 ignored;
реальные PostgreSQL acceptance/cancel/revocation/revision/recovery и populated
migration; 101 запрос к настоящему HTTP-серверу, резервная копия/восстановление,
отказ согласованно подделанного отчёта; отдельное физическое прерывание процесса
с незавершённой committed задачей, повторный запуск, interrupted и успешный
явный retry. Прежний скачанный отчёт совпал побайтно. Исправлена коллизия
ID импорта после восстановления; регрессия прошла с настоящей sequence.

В браузере проверены отправка, живой этап, итог, reload, повтор, скачивание
с проверкой CLI, отмена с reload. В узкой панели восстановлена навигация.
Первоначальные попытки отмены, в которых расчёт уже завершился или использовалось
неверное имя кнопки, не засчитаны. Успешный сценарий сохранён отдельно.

Ограничения: один экземпляр приложения, общий допуск двух операций и один CPU;
восемь сохранённых оценок проекта, ключ запроса живёт час, до 64 квитанций.
Предел 30 секунд кооперативный. Экспорт не содержит подпись автора; проверка
требует той же методики. Подробности — `QUALITY_JOBS_CONTRACT.md`, компактные
свидетельства — `../evidence/sprint26/durable-quality/local-checks.json`.

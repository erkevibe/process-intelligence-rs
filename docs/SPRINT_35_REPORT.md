Добавлены явное фиксированное UTC-смещение для дат без пояса, прежнее строгое
поведение при пустом выборе и временный просмотр длительностей по двум
колонкам. Просмотр показывает случаи короче/ровно/дольше границы, частоты,
длительность действий, подписанные интервалы конец→начало и возвраты A→B→A.
Сравнение границы и точные суммы сохраняют наносекунды; интерфейс округляет
только показ. Пустая группа получает no data, отрицательные интервалы не
обнуляются. Это не вывод причинного ожидания ресурса и не BPMN-conformance.

Формат хранения и схема6 сохранены. Две отметки используются только во
временном просмотре и его скачанном JSON; в журнал импортируется одна
выбранная отметка. Новый optional-параметр отсутствует в прежнем JSON-mapping,
если не задан. Матрица и метод оценщика BPMN не менялись.

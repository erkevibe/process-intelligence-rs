## 4. Mandatory live lifetime-counter handshake

The new harness first reads bounded command identity/nonce and obtains its actual PID, emits a bounded BOOT_READY protocol record, flushes stdout, and waits for exactly `GO <nonce>` on stdin before input reads, parser initialization, class identity reflection, allocation of benchmark models or application work. No static initializer may instantiate Jackson/miner/factory before this gate. Import declarations alone do not execute a Java algorithm. Root assigns the owned worker and its descendants to the new Job BEFORE releasing GO; no post-start assignment race is accepted as descendant ownership.

After every iteration the harness closes its actual BPMN exporter output, records byte count/SHA and complete observation/status/exception, appends and flushes a bounded iteration ledger. It keeps warmups and exceptions. Before terminal-ready it closes/forces all NEW result/ledger/BPMN files, writes a complete summary and its hashes, then emits `TERMINAL_READY` with actual PID, the same nonce, scheduled/completed call counts and summary/ledger hashes. It flushes the sentinel and blocks for exactly `EXIT <nonce>` before returning. Root verifies nonce/PID/native creation time/output hashes while the exact process is still alive, collects native lifetime counters, persists that receipt, then sends EXIT. No new algorithm/export work occurs after terminal-ready.

Unexpected EOF/nonce, invalid input, observer/export failure and native termination are explicit records. A caught ordinary miner Exception is an iteration outcome, not a successful graph; continue remaining scheduled calls with fresh parse/miner. A VM-fatal Error/abort/timeout may stop the batch; preserve its partial flushed ledger/native streams and mark every remaining call unexecuted_due_process_failure. Do not catch a fatal failure into a fabricated terminal success. Missing terminal-ready/lifetime counters is unavailable/inconclusive, never memory0. Handshake/readiness/terminal waits are bounded by the Root phase deadline and per-process limit.

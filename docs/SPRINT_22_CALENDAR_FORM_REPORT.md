# Sprint22: исправление ошибок календаря в форме

Продолжение R5 в первоначальном восьмичасовом лимите, после поставки
[предыдущего календарного этапа](SPRINT_22_CALENDAR_REPORT.md). Математика,
формат данных, API по умолчанию и разбор типов Axum не меняются.

При семантической ошибке браузер получает форму с введёнными значениями и
сообщением «Настройки не сохранены». Последние сохранённые результаты
показаны отдельно. Исправленный календарь сохраняется обычным POST с
перенаправлением; последующая загрузка показывает сохранённые настройки.

HTML включается только явным положительным `text/html` без положительного
`application/json` во всех заголовках Accept. Смешанный запрос с JSON,
одни wildcard, нулевой HTML или неверный q оставляют прежний JSON.
Для черновика свыше 16 KiB текстовых полей также остаётся JSON. Ошибки
разбора типов не перехватываются новым обработчиком.

Строки экранируются; неверные числовые значения сохраняются в полях без
переполнения. Перед выдачей HTML повторно проверяются текущие права записи.
Недоступный журнал, чужой проект и потеря прав не раскрывают черновик.
Страница ошибки имеет `no-store` и `Vary: Accept`.

Локальные факты:

- Шесть новых HTTP-тестов, три прежних теста пояснений и пять тестов
  календаря прошли. Проверены варианты Accept, опасные строки, крайние
  числа, большой ввод, отсутствующий журнал и исправление ошибки.
- Настоящие C02/C03 работали последовательно на отдельной базе PostgreSQL.
  Выполнены 15 и 28 запросов; сохранены 40 ответов. Прежний JSON совпал
  побайтно; неверный ввод не изменил полный экспорт и историю проекта.
- Ручные ожидания Берлина: весна — 7 200 000 мс, осень — 14 400 000 мс.
  Проверены читатель, повышение до редактора, отзыв записи и чужой проект.
  Это последовательные запросы, не доказательство всех конкурентных гонок.
- В настоящем браузере проверены неизвестная зона, конфликт смещения,
  строка с тегом script, исправление и явная перезагрузка. Черновик остался
  текстом; внедрённого элемента нет. Сохранённые 2/4 часа не изменились.
- Аудитор заново прочитал 42 файла / 76 525 байт и подтвердил конечные
  ожидания. PostgreSQL штатно остановлен. Процессы и вывод проверены отдельно.

Материалы — `evidence/sprint22-calendar-form`; независимый аудитор и инструкция —
`tools/sprint22-calendar-form`. Публичная сводка процессов охватывает только
сборку, стенд и аудит: 21 процесс / 42 потока. Три stdout опубликованы точно,
39 исходных потоков приватны. Их хеши не означают публичное повторение всех
оригиналов; подготовительные форматтеры и последующая поставка учитываются
отдельно. Прежние неудачи и шесть исторических UNKNOWN не пересматриваются.

Эта запись фиксирует локального кандидата. Поставка дополнительно требует
успешных CI точного коммита, проверки скачанных исходников и итогового
закрытия ресурсов; фактические результаты будут указаны в описании PR.
Полное закрытие R5, enterprise, исправление общего протокола STATUS и успех
преобразования 90 000 событий здесь не заявляются. Тот прогон по-прежнему
отклонён ограничением размера отчёта.

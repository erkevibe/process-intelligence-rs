# 0.7.5 — полный сервис импорта и подписи переходов BPMN

Пакет и точные исходники сборки опубликованы как предварительный выпуск. Root и независимый QA отдельно и анонимно скачали оба архива и проверили все файлы. Технический результат выбранного R2 принят пятью голосами. Итоговое подтверждение поставки — [публичная квитанция 0.7.5](https://github.com/erkevibe/process-intelligence-rs/releases/download/v0.7.5/0.7.5-delivery-receipt.json); до её публикации и проверки финальный статус поставки остаётся открытым.

## Изменения и границы

BPMN поддерживает `sequenceFlow.name`: импорт, отображение, редактирование подписи, сохранение, XML-экспорт и повторный импорт. Подпись сохраняет Unicode, пробелы и XML-символы; сервер проверяет предел 4096 UTF-8 байт. Это текст перехода. Условия, default flow и BPMNLabel DI по-прежнему отклоняются. Граф, координаты, размеры и точки переходов сохраняются.

Новая установка с PostgreSQL прошла настоящий браузерный сценарий: импорт → выбор перехода → изменение подписи → сохранение → экспорт отдельным HTTP-запросом → повторный импорт через браузер → перезапуск той же установки. Полные модели сравнивались, включая DI. Семь ресурсов совпали побайтно после перезапуска. Прежняя браузерная сессия сохранила доступ; затем отдельно проверен режим наблюдателя. Редактор сохранил изменение, устаревшая версия получила 409, наблюдатель — 403, чужой проект — 404. QA и TechnicalDebt проверили результаты независимо.

Проверены также XES-предпросмотр с уведомлением о полях вне анализа, явное согласие перед записью, исходный файл, история импорта и динамическое раскрытие трассы Datastar. Отчёт об опущенных метаданных в предпросмотре временный; долговечный аудит всех атрибутов не заявляется.

Сравнение Apromore теперь исполняет настоящий публичный транзакционный `importLog` неизменённого `EventLogServiceImpl`, включая реальные JPA/auth/storage/cache зависимости выбранной ветки. Полные результаты 12 Java-сценариев и пяти входов Rust опубликованы как [обезличенные доказательства](../evidence/sprint18/public-service/README.txt). Поддержанный [профиль импорта](R2_SELECTED_IMPORT_CONTRACT.md) принят отдельно после наблюдений. Полного паритета форматов, атрибутов, UUID, наносекунд, globals, rollback и всех веток сервиса нет. H2 в эталоне не выдаётся за проверку MySQL или Portal HTTP.

Отдельное сравнение настоящего Core-фильтра на восьми примерах даёт шесть полных совпадений и два диагностических различия. [Наблюдения и команда повторения](../evidence/sprint18/core-filter/README.txt) доступны в репозитории. Это проверка конечного `case_activity`, не всего R5. Диагностические файлы более поздних коммитов не входят задним числом в неизменный пакет приложения.

## Установка

Скачайте Windows ZIP из [релиза v0.7.5](https://github.com/erkevibe/process-intelligence-rs/releases/tag/v0.7.5), проверьте SHA256 и распакуйте в новую папку. Требуется PowerShell7; Rust и Java для запуска не нужны. В папке пакета:

```powershell
pwsh -NoProfile -File .\Start.ps1 -Port 3106 -PostgresPort 5486
```

Откройте `http://127.0.0.1:3106/`. Существующие установки и их данные сохраняйте отдельно. Если порт занят, выберите свободный. Для резервирования и восстановления используйте [STORAGE_V2.md](STORAGE_V2.md). Старые модели без подписи перехода читаются новой версией; старый бинарник может отказать на новых моделях с этим полем. Не откатывайте бинарник поверх новых данных.

Актуальный статус приёмки и поставки фиксируется в [отчёте Sprint18](SPRINT_18_REPORT.md) и квитанции релиза. Документы внутри неизменного архива отражают момент заморозки, последующие решения публикуются отдельно.

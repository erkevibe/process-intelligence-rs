# Семь упражнений Procure-to-Pay

Источник вопросов: https://apromore.com/process-mining-101, прочитан 25.10.2026.
Ответы ниже рассчитаны по текущим загружаемым файлам: 625 случаев,
9070 событий, 24 действия, 143 варианта. Хеши входов закреплены в
[плане Sprint35](SPRINT_35_PLAN.md). Исходные файлы не переопубликованы.

Для сравнения выбран исходный порядок строк, Start_Time/End_Time,
фиксированное +00:00 для дат без пояса и граница 28 суток. Это явная
расчётная конвенция, не установленный часовой пояс исходной системы.
Одинаковое смещение сохраняет разности; календарь и DST не применяются.

Результат установленного 0.12.0 совпал с самостоятельным разбором CSV/XLSX
для full/fast/slow: количества, точные суммы, частоты, интервалы и возвраты.
Браузер подтвердил полный просмотр на целевой HTTPS-установке. Сырые
протоколы и точные суммы сохранены приватно в apromore-exercises.

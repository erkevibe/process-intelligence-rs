# Sprint21 — предварительная проверка конфигурации

Статус: локальная целевая приёмка завершена. Публичный PR, CI и независимая
проверка опубликованных исходников ещё не завершены. План одобрен Советом:
`6DB9AD39B11A1DD5563A0174E81E3BF3A5DA2A778B1753E8A8C68FE03D9F7A1D`.
Жёсткий срок этапа вместе с поставкой — 23 октября 2026 года, 00:06:30 UTC.

## Зачем нужна проверка

В прежних попытках отсутствовали обязательные пути worker, а 227 хешей
были записаны строчными буквами при сравнении с учётом регистра. Эти ошибки
выявлялись слишком поздно, после подготовки тяжёлого запуска. Новый
отдельный валидатор проверяет конфигурацию до передачи принятому runner.
Он не меняет продукт, PostgreSQL, компилятор, прежние исходники CAP или
защитные лимиты и не исправляет шесть исторических UNKNOWN.

## Границы инструмента

`validate-config.py` не запускает дочерние процессы и не переписывает вход.
Он проверяет SHA256 самой конфигурации, обязательные поля и типы worker,
строгий JSON без повторяющихся ключей, абсолютные допустимые пути и
закреплённые файлы. Хеши требуют ровно 64 шестнадцатеричных символа верхнего
регистра; строчные значения отклоняются, а не исправляются молча.
Совпадающие после нормализации Windows пути не позволяют скрыть конфликт
закреплений. Отсутствующий файл или несовпадение его фактического SHA256
означает отказ.

Пределы проверки: 20 секунд, до 1 MiB конфигурации, 2 000 закреплений,
128 MiB на файл и 512 MiB суммарно. Оболочка `run.ps1` проверяет закреплённые
Python, валидатор, принятые runner и worker. Только успешная проверка
позволяет передать управление runner; режим `CheckOnly` этого не делает.

Рабочий каталог — явная доверенная точка: перед вызовом нужно перейти
в корень проверяемого проекта, а `Workspace` должен указывать туда же.
На обзоре исходника до запуска обнаружен ложный отказ из-за предков
OneDrive. Исправление ограничено предками этой точки: сама точка и её
потомки проверяются, а внешние пути сохраняют строгую проверку всех предков.
Это не проверка ACL и не доказательство корректности произвольной фазы.

Исторический runner ограничен 23 октября, 00:30:37 UTC. После этого времени
валидатор должен отклонять просроченную конфигурацию: инструмент не
превращает прежний runner в универсальный запускатель будущих этапов.

## Использование и проверки

Из корня проекта:

```powershell
.\tools\sprint21-preflight\run.ps1 -Workspace <корень> -Config <файл> -ConfigSha <SHA256> -Python <путь> -PythonSha <SHA256> -CheckOnly
```

Без `CheckOnly` успешная проверка передаёт управление принятому runner.
Параметры `Workspace`, `Config`, `ConfigSha`, `Python` и `PythonSha`
обязательны. Не используйте непроверенную конфигурацию ради проверки запуска.

Шесть контролей выполнены: корректная конфигурация в `CheckOnly` завершилась
с кодом 0; отсутствующие обязательные поля, строчный хеш, некорректный
шестнадцатеричный хеш, конфликт нормализованных путей и изменённые
закреплённые байты — каждый с кодом 2. Внешний процесс завершился с кодом 0;
семь непосредственных захватов имеют полные потоки без ошибок сборщика.
Маркера `RUNNER_DELEGATION` и выходного каталога нет; SHA256 конфигурации
не изменился. Приложение и измерения не запускались. Python наследует потоки
оболочки: отдельная идентичность или запись завершения процесса Python
этими захватами не доказывается.

SHA256 сохранённого результата:
`955B452A7CFDE82FEBD726522CC805E022EA03AEEA6D1332A84A59EE719741A1`.
Это ограниченный локальный результат, а не приёмка всего этапа.

Отдельно проверен обычный путь оболочки без `CheckOnly`: фактический вывод
содержит принятие 95 закреплений общим объёмом 97 973 413 байт, затем
`RUNNER_DELEGATION`. Внешний запуск завершился с кодом 0; все пять команд
чистой фазы проверки сохранённых свидетельств и её внешний процесс также
завершились с кодом 0 и полными потоками. Это наблюдение реального вывода
инструмента, а не новая запись отдельного PID или седьмой синтетический
контроль. Приложение, PostgreSQL и измерения не запускались.

Частный аудитор проверил фактические повреждения тестовых файлов; публичный
аудитор и проверка всего пакета прошли. Манифест учитывает 49 записей отбора,
шесть явных исключений и 44 опубликованных файла общим объёмом 17 204 байта.
В 14 разрешённых местах заменено только поле программы. Независимый QA
проверил исходники, результаты, точные числовые записи и отсутствие частных
данных, а также 13 непосредственных записей процессов.

По соразмерному контуру FLW локальная целевая приёмка завершена. Отдельная
публичная поставка — PR, оба CI точного коммита и полное независимое
скачивание исходников Root и QA с повтором проверок — пока остаётся
незавершённой. Итоговое закрытие будет отражено в описании PR. Новый помощник
не устанавливает причину прежнего тайм-аута обхода и не восстанавливает
отсутствующие коды завершения.

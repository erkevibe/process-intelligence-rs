# BPMN по полному учебному журналу

Профиль версии 0.13: `full_log_state_machine_v1`. Статус поставки и точные
проверенные коммиты — в [отчёте Sprint36](SPRINT_36_REPORT.md).

## Построить и проверить

1. Загрузите Procure-to-Pay CSV. Выберите `case_id`, `activity`, время события
   `End_Time`, исходный порядок строк и явное смещение для дат без пояса.
   Для просмотра длительностей дополнительно выберите `Start_Time`.
2. Откройте построение BPMN из журнала, выберите «Непосредственные переходы ·
   полный журнал» и запустите сохранение. Дождитесь завершения задания.
3. Откройте модель, скачайте BPMN и результат с входами. Оценка в построении
   относится к обучению. Для другого журнала откройте сохраняемую оценку,
   выберите полный профиль и нужный контрольный журнал.

Все случаи учитываются без выборки. Учебный файл содержит 625 случаев,
9070 событий, 24 действия и 143 варианта. Прежняя структурная эвристика
остаётся отдельным вариантом со своими меньшими пределами.

## Семантика и качество

`directly_follows_state_machine_v1` сохраняет наблюдённые начала, окончания и
непосредственные соседства. Каждая метка имеет одну задачу; XOR-узлы соединяют
альтернативы и возвраты. Модель может сочетать соседства из разных случаев и
разрешать ранее не встречавшиеся длинные пути. Параллельность не выводится.

На текущем учебном наборе: 76 узлов / 99 переходов, fitness 1,
precision 15723/18061, structural simplicity 225/271. Это обучение.
Fast/slow из того же full-журнала не являются независимым контролем модели,
обученной на full.

Однотокенность, завершимость и живость проверяются по всем достижимым
маркировкам конкретной сети. Это не доказательство свойств всех моделей
алгоритма. Неподдержанная параллельность и исчерпание поиска дают явные
отказы или неопределённость.

## Пределы

| Вход/операция | Предел |
|---|---:|
| Случаи / события | 1000 / 20000 |
| Действия / варианты | 32 / 256 |
| События в одном случае | 64 |
| Метка действия | 200 байт UTF-8, без управляющих символов |
| Узлы / переходы BPMN | 128 / 256 |
| Элементы / дуги полученной сети | 512 / 1024 |
| Достижимые состояния / состояния отдельного поиска | 1000 / 1000 |
| Общая очередь / вычислители | 2 / 1 |
| Сохранённые задания каждого вида | 8 |

Сохраняются права, отзыв доступа, отмена, идемпотентный ключ запроса,
привязка к ревизиям и interrupted после перезапуска. Повтор запускается явно.
Пределы сохраняемого JSON и квота проекта действуют дополнительно.
Допустимый размер входа не гарантирует завершения: сеть или поиск могут
исчерпать отдельный бюджет.

## Повторить скачанный отчёт

Для сохраняемой оценки команда различает прежний и полный профили:

```sh
./process-intelligence-rs --verify-quality-report quality-report.json
```

Численный повтор не подтверждает подпись автора. Для результата построения
и отдельно скачанной BPMN есть самостоятельная проверка XML/арифметики:

```sh
python3 tools/sprint36/audit-full-log.py --discovery-export discovery-report.json model.bpmn --self-test
```

В метаданных и входе полного профиля сохранён явный признак. Прежние записи
сериализуются без нового поля; исторический оценщик и его отпечаток сохранены.
Схема PostgreSQL 6 не меняется. Старый 0.12 отверг изолированную базу с новым
признаком без записи. Возврат после создания full-заданий требует согласованной
копии до обновления. Сырые учебные файлы в поставку не входят.

# Дата и состояние журналов: 0.6.1

Это контракт отдельного кандидата по [плану C06](SPRINT_08_C06_PLAN.md). Выбранный пакет принят новым решением Совета5/5 и опубликован как0.6.1. Независимая публичная QA и итоговый CI H6 завершены. Поставка A08 завершена 07:47 UTC; полный receipt проверен двумя независимыми ролями. Принятая 0.6.0 остаётся отдельной установкой; [отчёт](SPRINT_08_REPORT.md) указывает фактические версии и решения.

Список показывает имя, стабильный ID, число событий, дату сохранения в приложении и состояние «Сохранённый анализ». Дата задаётся сервером при подготовке успешной публикации и сохраняется вместе с результатом. Это UTC-время приложения, а не время событий, файла или точный момент SQL commit. Одинаковые названия не объединяют результаты: используйте ID и ссылку своей строки.

Старые журналы без сохранённой даты показывают «Дата не сохранена». Приложение не вычисляет её из имени, ID или старта. Изменение параметров и перезапуск сохраняют исходную дату; восстановленная копия сохраняет историческое поле. Для нового импорта обычного XES, CSV, подтверждённого preview и завершённой задачи применяется общая точка создания. Отказ или отмена не создаёт готовую строку.

Состояние означает, что результат опубликован и сохранён. Целостность тяжёлых данных проверяется при открытии; список читает только метаданные. Незавершённые и неуспешные обработки находятся в задачах. Список не объявляет нечитанный payload проверенным или исправным.

Экспорт нового журнала содержит `created_at` в RFC3339 UTC; отсутствующее старое поле остаётся отсутствующим. Явные `null`, число и неправильная строка даты отклоняются строгим decoder. Допустимая дата с RFC3339 offset нормализуется в UTC. Входной запрос импорта не задаёт серверную дату. Даты и actor из восстановленной истории не удостоверяют личность исторического автора.

Права, лимиты, исходник и история импорта следуют [контракту 0.6](SPRINT_08_RUNTIME.md). Новый кандидат не обновляет прежние пользовательские базы автоматически. Старым бинарником не обещано читать новый формат метаданных; перед сменой версии необходимы полный backup и восстановление в новую базу. Проверенный полный путь требует PowerShell 7.6.5; Windows PowerShell 5.1 используется для Start, полный backup 5.1 не заявлен.

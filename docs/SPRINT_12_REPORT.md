## Сохранённые неудачи и исправления проверок

Первый folder fixture ожидал400 вместо правильного422/folder_cycle. Продукт отказал корректно; прогон FAILED, независимый зачёт ограничен первыми пятью шагами. Исправленная полная проверка выполнена на новой установке. Аналогично сохранены ранние project/parser/native drafts и их причинные исправления; неудачная база не переоткрывалась ради повтора.

Первая mixed recovery остановилась до backup из-за имени PowerShell-функции Compare, пересекавшегося со встроенным alias. Уникальное имя и малая dispatch-регрессия исправили служебную причину. Затем вся последовательность повторена на новой установке с новыми состояниями и хешами мостов. Старая изменённая база сохранена; это не дефект продуктового EXE.

Первая браузерная попытка загрузки застряла во внешнем chooser/tool на2647 секунд и пережила20-минутный лимит fixture. Import POST не выполнялся. Новый короткий браузерный маршрут использовал заранее загруженные API данные; browser upload не приписывается этому успеху.

Первоначальная QA-находка о неизменившемся графе была ошибкой сопоставления изображений в пакетном просмотре. Снимки прочитаны по одному: три видимых ребра стали нулём при пороге2, статистика сохранилась. Находка отозвана отдельным неизменным исправлением `AE56EBF4863EB0DED78FAC1D44137B5022441BE35FC2915C19AB3160A8444606`; исходный ошибочный отчёт сохранён. Нового продуктового дефекта или исправления0.7.3 из этого не следует.

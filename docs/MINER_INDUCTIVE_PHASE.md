# Дополнительная реализация: PM4Py Inductive Miner

Зафиксировано до первого вызова этого майнера, 24.10.2026.
Установленный проверочный комплект уже содержит PM4Py2.7.17 и настоящий
`algo.discovery.inductive.algorithm`, варианты IM/IMf/IMd. Это Python,
лицензия поставленного пакета AGPL3; наличие Rust Inductive не заявляется.

Проверяем ровно классический `Variants.IM`, без фильтра шума и подбора порогов.
Используем оба ранее замороженных корпуса целиком, два повтора каждого случая.
Алгоритму передаётся только training XES, без JSON с контрольными трассами.
Пустой training — явный no_data без вызова алгоритма. Каждый процесс ограничен
60 секундами и 512MiB private commit до запуска, вывод ограничен.

Сохраняем process tree, исходные Petri net и BPMN, точные входы/параметры,
native время/пики. Проекция BPMN сохраняет все задачи, шлюзы и связи;
неподдержанное — отказ. До оценки общий Rust-фасад должен принять модель.
Независимо проверяем полноту графа, язык исходной сети и исходного XML,
экспорт/импорт, детерминизм и все численные группы прежним PM4Py reference.
Новые удачные результаты не отменяют прежних отказов Alpha/SplitMiner.

Критерии допуска прежние из MINER_EXPERIMENT.md. Решение о поставке Python
или отдельной нативной реализации принимается после результатов, с учётом
лицензии, размеров и поддержки окружения; исследовательский успех сам по
себе не добавляет внешний runtime в продукт.

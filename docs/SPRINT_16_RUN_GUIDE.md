# Проверка кандидата 0.7.4

Приёмка не завершена: спринт остановлен по восьмичасовому лимиту. До появления итогового решения и точного SHA256 в релизе этот документ не подтверждает готовность выпуска. Локальная проверка разрешена пользователем; её продолжению нужен новый временной бюджет.

Используйте новую папку и PowerShell 7. Не распаковывайте поверх прежней установки и не подключайте к проверочному запуску пользовательскую БД. Самостоятельный запуск пакета не требует Rust или Java. Java/Gradle нужны только отдельному диагностическому эталону Apromore.

После проверки SHA256 опубликованного ZIP распакуйте его и запустите `Start.ps1` через `pwsh`. По умолчанию приложение использует порт 3000, PostgreSQL — 5433. Если порт занят, выберите другой свободный через `-Port` и `-PostgresPort`; не останавливайте неизвестный процесс. Данные новой установки создаются в её защищённой `.local`. Первый аккаунт новой пользовательской установки создаёт пользователь.

В разделе журналов выберите предпросмотр импорта с подтверждением. Для `fixtures/oracle-full-service/typed-flat-attributes.xes` перед подтверждением видны ключи, типы и количество метаданных, которые не попадут в анализ. Их значения не выводятся. Полный исходный XES сохраняется после подтверждения, а плоский CSV и анализ используют ограниченное представление. Предупреждение не означает поддержку вложенных атрибутов, глобальных значений, gzip или MXML — строгий продуктовый допуск продолжает их отклонять.

Импортируйте `fixtures/sprint02/linear.bpmn`, измените подпись и координаты задачи, сохраните и экспортируйте BPMN. Размеры фигур из DI должны сохраниться. Перезапустите приложение и откройте ту же модель. Редактор поддерживает конечный набор start/end/task/exclusive/parallel и sequence flows, а не произвольный BPMN или исполняемый процессный движок.

Новая версия читает прежние модели без поля размеров. Старый бинарник может отказаться читать новую модель с этим полем. Не используйте старый бинарник для отката поверх данных, изменённых новой версией. Сохраняйте прежнюю установку и независимую резервную копию; общие инструкции резервирования и восстановления находятся в [STORAGE_V2.md](STORAGE_V2.md). Новая проверка не даёт автоматического подтверждения полной цепочки под Windows PowerShell 5.1.

Настоящий SplitMiner пока исполнялся как отдельный закреплённый Java-эталон на восьми примерах. В пользовательском Rust-приложении он не появился. Alpha+++ из Rust4PM остаётся отдельно обозначенным алгоритмом. См. [отчёт](SPRINT_16_REPORT.md), [полный импортный эталон](FULL_SERVICE_ORACLE.md) и [роадмап](ROADMAP.md).

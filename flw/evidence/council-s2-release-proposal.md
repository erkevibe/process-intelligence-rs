## Проверенная граница

Свежие release build и 49 обычных тестов прошли. Два PostgreSQL-теста в обычном запуске явно ignored и отдельно реально исполнены QA на изолированной БД: CAS, rollback, sessions, access, restore/version/order и restart. Проверены jobs, исходные/отфильтрованные журналы, два одноимённых журнала после рестарта, роли, повреждённые backup, пределы моделей/журналов, столкновения IDs и потеря lease. Root проверил fmt/clippy точного frozen source; QA и Root независимо проверили 150 frozen-файлов и SHA EXE. Пять отрицательных проверок упаковки отклоняют подмены и грязные входы до создания результата; TD не принимает самостоятельно два authored build/package инструмента.

Чистый ZIP содержит 1635 проверенных файлов. Реально создан bundled PostgreSQL; приложение работает от nonsuperuser, rollback probe прошёл. Каталог `.local` имеет одну явную FullControl-запись текущего пользователя, без наследования; независимый QA подтвердил отсутствие административной привилегии. В Windows PowerShell5 проверено восстановление существующей роли с отсутствующей тестовой БД. Native public Start прошёл в стандартном окружении модулей Windows PowerShell5, с per-process ExecutionPolicy Bypass, без изменения глобальной политики.

Actual packaged browser: CSV → project → filter → calendar → BPMN Apply/Save → XML/analysis/backup export → restore в новый проект; чужие известные IDs отклонены. Дополнительно viewer/editor и actor isolation. После настоящего перезапуска точного packaged EXE данные и модель повторно проверены браузером. Это закрывает A12 выбранного объёма.

## Сохранённые отказы и пределы

Предыдущие кандидаты не принимаются задним числом. В истории сохранены: restore timestamp-order gap; missing NOTICE/caller CWD; свежий Set-Acl с SeSecurityPrivilege; тестовая коллизия порта5434; native PS5 UTF8 em-dash parser failure. Причины исправлены до новой проверки. Inherited Codex PS7 PSModulePath вызвал отдельный отказ Get-FileHash; исправлено только окружение дочернего verifier до стандартного Windows PowerShell5. Произвольное загрязнённое cross-shell окружение не сертифицировано. Ошибки приватного verifier redirect/expected status исправлены по фактическому HTTP303 и новым login-проверкам; проверки продукта не ослаблены.

Исходные stderr двух ранних native-launch попыток были перезаписаны повторным использованием имени файла; диагностические tool outputs и описание причин сохранены, полное историческое raw-log покрытие не заявляется. QA сообщает покрытие только конкретных остановленных snapshots.

Умеренные ограничения: явные DB deadlines и измеренный RSS ещё отсутствуют; прерывание между initdb и записью private config требует восстановления; модель сохраняется через Apply затем Save; пароль измеряется UTF8 bytes. Они отражены в debt/Customer evidence. Нет открытого обязательного STOP на выбранном локальном сценарии.

Полные исходные R2–R5 не объявляются завершёнными. Legacy oracle/Apromore equivalence, arbitrary BPMN, Split Miner quality, DST/IANA, folders, SSO/TLS/network deployment, distributed jobs и enterprise readiness остаются дальнейшей дорожной картой.

## Решение, которое предлагается

Принять A01–A12 выбранного S2-P1 и публиковать эту точную 0.2.0 поставку через публичный PR/release. После голосования допускается commit только отчётов/документации/evidence; он не меняет принятые runtime inputs и SHA архива. Merge/tag commit и source commit архива указываются раздельно. Установка для пользователя отдельная и без QA accounts; R1 с возможными несохранёнными данными не останавливается.

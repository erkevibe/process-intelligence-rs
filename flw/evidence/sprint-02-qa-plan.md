## ProcessLogAuditor observation contract

Connect observation **before** PostgreSQL/bootstrap/migrations/backup restore and builds. Root owns processes; auditor reads available logs without claiming to intercept every command. Inventory each source as captured/full completed snapshot, captured/growing snapshot, truncated, missing, disabled or not-in-run; record timestamps, byte size, hash and applicable source/run identity. Agent messages and root's process exits are attributed reports unless independently read. A file hash while growing is only a snapshot.

Required sources: setup/distribution hash/probe logs; schema/migration/version and transaction failures; test/build/clippy results; application request/auth decisions, durable job state/publication/recovery, backup/restore outcomes; FLW decisions/STOP/RESUME; exact candidate/CI/package metadata. Public summary contains safe codes/counts and redacted identities, not passwords/session tokens/raw headers or real customer CSV/backups. Authentication failures expected by tests are classified separately from unhandled errors. A disabled INFO stream is disclosed, not treated as zero incidents.

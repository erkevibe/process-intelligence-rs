# Process Intelligence Core на Rust

Открытый проект для постепенного переноса поведения Apromore Core на Rust. Первый этап — локальный прототип анализа XES: импорт, статистика, варианты трасс, DFG и интерактивная фильтрация.

Статус на 10 октября 2026 года: подготовлены документы для защиты плана. Разработка приложения ещё не начата. Это самостоятельный проект, не официальный релиз Apromore.

## Предлагаемый стек

Rust, Axum, Tokio, серверные HTML-шаблоны, Datastar в CSP-режиме, Cytoscape как компонент графа. Rust4PM используется через адаптер после проверки API и поведения. PostgreSQL и Arrow/Parquet относятся к следующим этапам.

## Правило готовности

Задача готова, когда проверяемый результат воспроизводится на зафиксированной версии кода. Гипотезы, результаты выполнения и проверенные решения хранятся раздельно. Совместимость с Apromore заявляется только по сценариям, проверенным против конкретной версии legacy.

## Лицензии

Лицензия нового кода выбирается после проверки состава зависимостей. До этого отдельная лицензия на новый код не объявлена. Повторное использование материалов Apromore требует учёта лицензий конкретных файлов. Исходная частная переписка и пользовательские журналы событий в репозитории не публикуются.
